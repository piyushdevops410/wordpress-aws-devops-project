A modern, lightweight WordPress block theme built for full site editing with reusable block patterns and a clean design system.

== Description ==

CoreFlux is a modern WordPress block theme designed for performance, flexibility, and ease of use. It leverages the power of Full Site Editing (FSE) and Gutenberg blocks to create dynamic and customizable layouts without requiring coding knowledge.

The theme includes a set of pre-designed block patterns such as hero sections, blog grids, feature sections, testimonials, and call-to-action layouts, making it easy to build professional websites.

CoreFlux follows WordPress coding standards, accessibility guidelines, and best practices, making it suitable for submission to the WordPress.org theme repository.

== Features ==

* Full Site Editing (FSE) support
* Pre-built block patterns
* Responsive design
* Custom color palette and typography
* Global design system via theme.json
* Lightweight and fast performance
* Translation-ready

== Installation ==

1. Upload the theme files to the `/wp-content/themes/coreflux` directory, or install the theme through the WordPress themes screen directly.
2. Activate the theme through the 'Themes' screen in WordPress.
3. Customize your site using the Site Editor (Appearance → Editor).

== Frequently Asked Questions ==

= Does this theme support Full Site Editing? =

Yes, CoreFlux is a block theme fully compatible with Full Site Editing.

= Can I customize layouts without coding? =

Yes, you can use the Site Editor and block patterns to customize layouts visually.
