A powerful Gutenberg block to display client testimonials with a responsive slider, customizable styles, and rating support.

== Description ==

Client Voice Slider is a modern Gutenberg block plugin that allows you to display client testimonials in a beautiful slider layout directly inside the WordPress block editor.

This plugin is designed for performance, flexibility, and ease of use. It allows users to add multiple testimonials, customize colors, control slider behavior, and choose different layouts without any coding.

Perfect for agencies, freelancers, business websites, and portfolios.

= Key Features =

* Custom Gutenberg block for testimonials
* Add unlimited testimonials
* Avatar image upload for clients
* Star rating system (1–5 stars)
* Responsive slider (desktop / tablet / mobile controls)
* Autoplay and speed control
* Multiple testimonial layouts (Card, Quote, Minimal)
* Customizable colors:

  * Background color
  * Text color
  * Name color
  * Company color
  * Arrow color
  * Pagination dot color
* Testimonial management:

  * Add testimonial
  * Delete testimonial
  * Duplicate testimonial
  * Reorder testimonials
* Avatar shape selector (circle, rounded, square)
* Fully responsive design
* Lightweight and fast

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/client-voice-slider` directory, or install the plugin through the WordPress plugin screen directly.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Open the **Block Editor (Gutenberg)**.
4. Search for **Client Voice Slider** block.
5. Add testimonials and customize settings.

== How to Use ==

1. Edit any page or post using the **Gutenberg editor**.
2. Click **Add Block (+)**.
3. Search for **Client Voice Slider**.
4. Add testimonials using the **Add Testimonial button**.
5. Customize design settings from the **Block Settings Panel**.

== Frequently Asked Questions ==

= Can I add multiple testimonials? =

Yes, you can add unlimited testimonials within the block.

= Can I change the slider speed? =

Yes, you can control autoplay and slider speed from the block settings.

= Is the slider responsive? =

Yes. You can define slides for desktop, tablet, and mobile.

= Does it work with any theme? =

Yes. The plugin works with any modern WordPress theme that supports Gutenberg.
