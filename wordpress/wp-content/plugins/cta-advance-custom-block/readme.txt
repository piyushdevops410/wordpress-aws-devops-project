A Gutenberg Call To Action block with advanced styling and customization options.

== Description ==

CTA Advance Custom Block allows you to create modern, responsive, and highly customizable Call To Action sections directly in the WordPress block editor.

You can add titles, descriptions, buttons, and control layout, colors, spacing, and design elements to improve user engagement and conversions.

Perfect for:

* Marketing sections
* Landing pages
* Product promotions
* Service highlights

== Features ==

* Gutenberg native block
* Add title and description
* Customizable call-to-action button
* Advanced styling options (colors, spacing, layout)
* Full width and boxed layout support
* Responsive design
* Lightweight and fast

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/cta-advance-custom-block` directory, or install via the WordPress plugins screen.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Open the **Block Editor**.
4. Search for **CTA Advance Custom Block**.
5. Add the block and customize your CTA section.

== Frequently Asked Questions ==
