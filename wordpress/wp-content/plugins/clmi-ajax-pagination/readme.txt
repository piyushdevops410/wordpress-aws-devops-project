Powerful AJAX pagination plugin for WordPress with Load More button, numbered pagination, and infinite scroll — no page reload required.

== Description ==

CLMI AJAX Pagination allows you to add dynamic, fast, and user-friendly AJAX-based pagination to your WordPress website without reloading the page.

Improve user experience and performance by loading posts asynchronously using:

* Load More button
* Numbered pagination
* Infinite scroll

The plugin is easy to use, highly customizable, and works with posts, pages, and custom post types.

Perfect for blogs, portfolios, news websites, and dynamic content listings.

== Features ==

* AJAX-powered pagination (no page reload)
* Load More button support
* Infinite scroll functionality
* Numbered pagination option
* Works with custom post types
* Easy-to-use shortcode
* Customizable styles (button color, text color, spacing)
* Lightweight and optimized
* Developer-friendly and extendable

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/clmi-ajax-pagination` directory, or install via the WordPress plugin screen.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Go to **AJAX Pagination** settings from the admin menu.
4. Configure your pagination settings.
5. Add the shortcode `[clmi_posts]` to any page or post.

== Usage ==

Basic shortcode:

`[clmi_posts]`

Display posts from a custom post type:

`[clmi_posts post_type="portfolio"]`

== Frequently Asked Questions ==

= Why are posts not displaying? =

Please ensure:

* The plugin is activated
* You have published posts
* The shortcode is added correctly
* Correct post type is selected in settings

= Can I use it with custom post types? =

Yes, you can select a custom post type from the plugin settings or pass it via shortcode.

= Does it support infinite scroll? =

Yes, infinite scroll can be enabled from the plugin settings.

= Does it work with any theme? =

Yes, it works with most well-coded WordPress themes.
